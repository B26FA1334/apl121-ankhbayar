# APL121 Бие даалт №1 - Code Quest

**Сэдэв:** Голч дүн (GPA) - n хичээлийн оноо -> үсгэн үнэлгээ (else-if) -> кредитээр жигнэсэн голч; дүнгийн хуудас; хамгийн өндөр 3 дүн.

## Ажиллуулах команд
```
gcc main.c -o main
./main        (Windows: main.exe)
```
Flowgorithm: `quest.fprg` нээгээд Run дарна.

## Миний тогтоосон дүрмүүд
| Оноо | Үсэг | Point |
|------|------|-------|
| 90-100 | A | 4.0 |
| 80-89.99 | B | 3.0 |
| 70-79.99 | C | 2.0 |
| 60-69.99 | D | 1.0 |
| 0-59.99 | F | 0.0 |

- Хичээлийн тоо: 3-аас 8
- Кредит: 1-ээс 6
- Оноо: 0-ээс 100
- Жигнэсэн голч = (point x кредит)-ийн нийлбэр / нийт кредит
- "Тэргүүний оюутан": голч >= 3.5 && F дүнгүй
